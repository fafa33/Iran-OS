# قراردادهای هوشمند

این بخش شامل قراردادهای هوشمند (Smart Contracts) پروژه Iran-OS است.

قراردادها وظیفه اجرای خودکار قوانین منشور، پروتکل‌های اقتصادی، سقف نقدینگی، شفافیت مالی و مدیریت صندوق ثروت ملی را بر عهده دارند.

نمونه وظایف قراردادها:
- قفل سقف نقدینگی
- جلوگیری از خلق پول بدون پشتوانه
- مدیریت صندوق ثروت ملی
- تخصیص بودجه
- قراردادهای رفاهی
- پروتکل بازپس‌گیری دارایی
- نظارت شفاف حاکمیتی
- مکانیزم‌های ماشه اضطراری
- اوراکل‌های اقتصادی و مالی

فناوری اصلی:
- Solidity
- Smart Contracts
- ZK Infrastructure
- API3 Oracles
