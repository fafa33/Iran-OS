## قراردادهای هسته (Core)

### IranOS_Kernel.sol

قلب سیستم. سه اصل غیرقابل تغییر را در لایه صفر قفل می‌کند:

- دوری آرتش از سیاست
- فرمول ریاضی ثروت ملی
- الگوریتم ماشه

**وابستگی‌ها:** TriggerProtocol.sol، ConstitutionGuard.sol

### TriggerProtocol.sol

مکانیسم ماشه خودکار. در صورت تخلف از شش خط قرمز (TR-01 تا TR-06)، بدون نیاز به دستور انسانی فعال می‌شود.

**رویدادها:** `TriggerActivated`, `AccessRevoked`, `BudgetFrozen`

### ConstitutionGuard.sol

تطبیق‌دهنده تمام مصوبات با اصول منشور. هر قانونی که از API این قرارداد عبور نکند، در شبکه اعتبار ندارد.

## قراردادهای پولی (Monetary)

### PahlaviToken.sol

- استاندارد: ERC-20 با سقف سخت‌افزاری
- سقف عرضه: ۹۰۰,۰۰۰,۰۰۰,۰۰۰ واحد (قفل شده)
- واحد فرعی: سره (۱ پهلوی = ۱۰۰۰ سره)
- هیچ مقامی توان mint مازاد بر سقف را ندارد

### SovereignWealthFund.sol

- مدیریت سه لایه: L1 (نقد)، L2 (مولد)، L3 (گرو)
- نظارت مستقیم پادشاه + شورای نخبگان مالی
- هر تراکنش نیازمند Multi-Sig

### MonetaryPolicy.sol

- اجرای قانون Proof of Reserve
- نسبت پشتوانه حداقل ۳۳.۳٪
- اتصال مستقیم به PriceOracle.sol

### VelocityFee.sol

- کارمزد رکود پلکانی (۲٪ تا ۸٪)
- آستانه: بالای ۱۰۰,۰۰۰ پهلوی، بی‌تراکنش ۳۶۵ روز
- معافیت استیکینگ خودکار

## قراردادهای رفاهی (Welfare)

### WelfareCard.sol

- صدور و مدیریت کارت ملی هوشمند رفاه
- ذخیره سهمیه دارو، بیمه و خدمات
- هویت دیجیتال بیومتریک شهروند

### BaseIncome.sol

- واریز خودکار ۱۰۰۰ پهلوی ماهانه به شاغلان
- تامین از سود لایه L2 صندوق ثروت ملی
- بدون نیاز به تایید دستی

### HealthCoverage.sol

- بیمه همگانی رایگان برای تمام شهروندان
- پرداخت آنی به مراکز درمانی از کیف پول سلامت شهروند
- «بودجه به دنبال بیمار می‌رود»

## قراردادهای حاکمیتی (Governance)

### Parliament.sol

- ثبت و اجرای مصوبات مجلس شورای ملی
- تایید بودجه سالانه و نظارت بر هزینه‌کرد دولت
- هر مصوبه نیازمند دستینه دیجیتال پادشاه

### Provincial.sol

- اجرای فرمول ۳۰/۷۰ توزیع بودجه استانی
- واریز خودکار ۳۰٪ درآمد استانی به حساب توسعه همان استان
- غیرقابل مسدودسازی توسط دولت مرکزی

### VotingSystem.sol

- رای‌گیری دیجیتال بیومتریک
- ثبت آنی و غیرقابل تغییر آرا در بلاک‌چین
- تقلب از نظر فنی غیرممکن

-----

## قراردادهای قضایی (Justice)

### JusticeProtocol.sol

- API قضایی واحد — تنها درگاه رسمی احکام
- هر حکم بدون امضای دیجیتال معتبر، در شبکه بی‌اعتبار است
- ثبت غیرقابل حذف تمام احکام

### JurySelection.sol

- انتخاب تصادفی ۱۲ داور ملی با الگوریتم VRF
- حفاظت از هویت داوران با ZKP
- آستانه محکومیت: ۸ از ۱۲ رای

### PenalLabor.sol

- مدیریت درآمد کار جبرانی محکومان
- اولویت‌بندی خودکار: هزینه نگهداری → غرامت قربانی → مالیات ملی
- واریز مستقیم به گنجینه آسیب‌دیدگان

-----

## قراردادهای بازپس‌گیری (Reclaim)

### SovereignCrawler.sol

- هوش مصنوعی توزیع‌شده برای شناسایی دارایی‌های غصبی
- ردیابی زنجیره‌ای شرکت‌های پوششی (Shell Companies)
- هدف: شناسایی کامل ظرف ۷۲ ساعت

### AssetFreeze.sol

- انجماد آنی دارایی‌های شناسایی‌شده
- ابطال امضای دیجیتال مدیران فعلی
- انتقال کلید مدیریتی به کیف‌پول موقت صندوق

### VictimFund.sol

- مدیریت گنجینه حمایت از آسیب‌دیدگان
- پرداخت غرامت به قربانیان مستقیم فساد
- گزارش‌دهی شفاف عمومی

## اوراکل‌ها (Oracles)

### API3Oracle.sol

- اتصال داده‌های دنیای واقعی به قراردادهای هوشمند
- منابع: زنجیره ارزش ملی، C4I، دفتر کل عمومی، سامانه قضایی
- چند منبع مستقل برای جلوگیری از دستکاری

### PriceOracle.sol

- قیمت‌های جهانی برای تثبیت ارزش پهلوی
- نرخ تورم جهانی برای تنظیم مستمری‌ها
- شاخص‌های بهره‌وری صنایع

### ProductionOracle.sol

- داده‌های واقعی تولید کارگاه‌ها برای Proof of Merit
- میزان فعالیت صنایع از طریق سامانه برق و لجستیک
- رتبه‌بندی خودکار واحدهای تولیدی

## راهنمای توسعه

### پیش‌نیازها

```bash
node >= 18.0.0
npm >= 9.0.0
git >= 2.30.0
```

### نصب

```bash
git clone https://github.com/fafa33/Iran-OS.git
cd Iran-OS/contracts
npm install
```

### اجرای تست‌ها

```bash
# تست تمام قراردادها
npx hardhat test

# تست یک قرارداد خاص
npx hardhat test test/core/TriggerProtocol.test.js

# گزارش پوشش تست
npx hardhat coverage
```

### استقرار محلی

```bash
# راه‌اندازی شبکه محلی
npx hardhat node

# استقرار قراردادهای هسته
npx hardhat run scripts/deploy-core.js --network localhost
```

```

✅ مستندات NatSpec برای تمام توابع

❌ هیچ Backdoor یا دسترسی مخفی مجاز نیست
```
