## Project model

Iran-OS is a publicly auditable, source-available, open-participation project. Source visibility exists to support transparency, public review, research, security analysis, education, evaluation, and technical contribution. Public source availability does not transfer ownership and does not grant commercial, institutional, governmental, or production-deployment rights except as expressly licensed.

## Operative source-available license

The intended operative project license for project-owned material after the licensing transition is `LICENSE-SOURCE-AVAILABLE.md`, using the repository SPDX reference `LicenseRef-IranOS-Source-Available-1.0` for project-owned source files.

The licensing transition is complete only when the root license, project-owned SPDX headers, canonical public documentation, package metadata, contribution terms, and third-party notices are internally consistent in the same transition boundary.
