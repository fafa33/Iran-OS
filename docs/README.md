# Iran-OS

## سیستم‌عامل حکمرانی دیجیتال ایران

Iran-OS یک پروژه متن‌باز (Open Source) برای طراحی و توسعه نخستین زیرساخت حکمرانی دیجیتال، اقتصاد ضدتورمی و معماری شفافیت ملی مبتنی بر بلاک‌چین، قراردادهای هوشمند و صندوق ثروت ملی است.
