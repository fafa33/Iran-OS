# Code of Conduct

## Purpose

Iran-OS is a public, source-available, open-participation governance infrastructure project.

This project welcomes technical, legal, economic, security, documentation, audit, formal verification, and governance review contributions.

All participation must remain respectful, evidence-based, reviewable, and focused on improving the project.

## Expected Behavior

Participants are expected to:

- be respectful and professional
- discuss ideas, code, evidence, tests, documents, and architecture rather than attacking people
- provide clear reasoning, sources, tests, evidence, or review notes when possible
- keep political, technical, legal, and governance discussions structured and relevant to the project
- respect the project’s non-claim rules around production readiness, audit completion, formal verification, release approval, and blocker closure
- respect the repository `LICENSE`; public source availability and participation do not grant commercial, institutional, governmental, or production-deployment rights beyond those terms

## Unacceptable Behavior

The following behavior is not acceptable:

- harassment, threats, insults, humiliation, or personal attacks
- spam, trolling, or deliberate disruption
- doxxing or exposing private information
- submitting false claims of evidence, signoff, audit completion, or blocker closure
- representing Iran-OS as production-ready without accepted evidence and required reviewer signoff
- using issues or pull requests for unrelated propaganda, abuse, or bad-faith disruption

## Project-Specific Rules

Iran-OS is not production-ready.

Contributors must not claim:

- production readiness
- release approval
- completed external audit
- completed formal verification
- accepted evidence
- closed `STEP9-BLOCK-*` blockers

unless the required evidence and reviewer signoff are attached or clearly linked.

## Enforcement

Maintainers may edit, hide, close, or remove issues, pull requests, comments, or contributions that violate this Code of Conduct.

Repeated or severe violations may result in restricted or blocked participation.

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub Issues
- Pull Requests
- Discussions
- documentation contributions
- review and audit submissions
- external collaboration spaces directly connected to Iran-OS
