# آیین‌نامه رفتار مشارکت‌کنندگان

## هدف

Iran-OS یک پروژه عمومی، متن‌باز و حاکمیتی است.

این پروژه از مشارکت‌های فنی، حقوقی، اقتصادی، امنیتی، مستنداتی، audit، formal verification و بازبینی حکمرانی استقبال می‌کند.

تمام مشارکت‌ها باید محترمانه، مستند، قابل بررسی و متمرکز بر بهبود پروژه باشند.

## رفتار مورد انتظار

مشارکت‌کنندگان باید:

- محترمانه و حرفه‌ای رفتار کنند.
- درباره ایده، کد، سند، تست، evidence و معماری بحث کنند، نه حمله شخصی به افراد.
- در صورت امکان، استدلال، منبع، تست، evidence یا یادداشت بازبینی ارائه کنند.
- بحث‌های سیاسی، فنی، حقوقی و حکمرانی را ساختارمند و مرتبط با پروژه نگه دارند.
- قواعد non-claim پروژه درباره آمادگی تولید، audit، formal verification، تأیید انتشار و بسته‌شدن blockerها را رعایت کنند.

## رفتار غیرقابل قبول

موارد زیر قابل قبول نیستند:

- توهین، تهدید، آزار، تحقیر یا حمله شخصی
- اسپم، ترولینگ یا اخلال عمدی
- افشای اطلاعات خصوصی افراد
- ثبت ادعای نادرست درباره evidence، signoff، audit completion یا blocker closure
- معرفی Iran-OS به‌عنوان production-ready بدون evidence پذیرفته‌شده و signoff معتبر
- استفاده از issue یا pull request برای تبلیغات نامرتبط، سوءاستفاده یا اخلال بدخواهانه

## قواعد ویژه پروژه

Iran-OS در وضعیت فعلی production-ready نیست.

مشارکت‌کنندگان نباید بدون evidence پذیرفته‌شده و signoff معتبر ادعا کنند:

- آمادگی تولید
- تأیید انتشار
- تکمیل audit بیرونی
- تکمیل formal verification
- پذیرفته‌شدن evidence
- بسته‌شدن `STEP9-BLOCK-*`

## اجرا

نگهدارندگان پروژه می‌توانند issue، pull request، comment یا مشارکت‌هایی را که این آیین‌نامه را نقض می‌کنند، ویرایش، مخفی، ببندند یا حذف کنند.

نقض شدید یا تکراری می‌تواند باعث محدودشدن یا مسدودشدن مشارکت شود.

## دامنه

این آیین‌نامه در همه فضاهای مرتبط با پروژه اعمال می‌شود، از جمله:

- GitHub Issues
- Pull Requests
- Discussions
- مشارکت در مستندات
- audit و review
- همکاری‌های بیرونی مرتبط با Iran-OS
