## 🎯 فراخوان همکاری برای برنامه‌نویسان
ما از تمامی متخصصان بلاک‌چین، معماران سیستم و توسعه‌دهندگان Full-stack دعوت می‌کنیم تا در تبدیل مفاهیم سپیدنامه به کد عملیاتی (Smart Contracts) مشارکت کنند.

### بخش‌های کلیدی برای توسعه:
* **هسته سخت (Kernel):** پیاده‌سازی منطق مکانیسم ماشه.
* **سیستم پولی پهلوی:** طراحی پروتکل Stablecoin با پشتوانه دارایی‌های فیزیکی.
* **لایه ZK-Rollups:** بهینه‌سازی تراکنش‌های ملی با کارمزد صفر.
* **اوراکل‌های API3:** اتصال داده‌های واقعی منابع ملی به شبکه.

## 🛠 نحوه مشارکت (Contribution)
ما به دنبال **«کد تمیز»** برای یک **«وطن پاک»** هستیم. 
شما می‌توانید با بررسی سپیدنامه، پیشنهادات فنی خود را در قالب **Issue** مطرح کنید یا برای پیاده‌سازی هر بخش، **Pull Request** بفرستید.
