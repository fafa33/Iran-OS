# پروتکل‌های اجرایی ایران‌اواس (IranOS Protocols)

## خلاصه هر پروتکل

### ۱. [پروتکل ماشه](./trigger-protocol-fa.md)

ستون فقرات کل سیستم. سازوکار خودکار و غیرقابل بازگشت برای اجرای منشور ملی. هر تخلف از خطوط قرمز (سکولاریسم، یکپارچگی ارضی، سقف نقدینگی و…) را بلافاصله شناسایی و بدون نیاز به دستور انسانی پیامدهای اجرایی را فعال می‌کند.

**فناوری‌های کلیدی:** Oracle API3، Multi-Sig، Smart Contracts، Decentralized Nodes

-----

### ۲. [پروتکل پولی](./monetary-protocol-fa.md)

معماری واحد پول ملی پهلوی. سقف نقدینگی ۹۰۰ میلیارد واحد را در پروتکل ZK-Rollups قفل می‌کند و از خلق پول بی‌پشتوانه جلوگیری می‌کند. شامل مکانیسم کارمزد رکود (Velocity Fee) برای گردش دائمی نقدینگی و واحد فرعی «سره» برای مقیاس‌پذیری بلندمدت.

**فناوری‌های کلیدی:** ZK-Rollups، Hard Cap، dAPIs، Proof of Reserve

-----

### ۳. [پروتکل دادگستری](./justice-protocol-fa.md)

حذف دادگاه‌های موازی و استقرار یک API قضایی واحد. انتخاب تصادفی داوران ملی از طریق الگوریتم VRF، حفاظت از هویت داوران با ZKP، و ثبت غیرقابل تغییر احکام بر بلاک‌چین. هیچ حکمی بدون امضای دیجیتال معتبر دادگستری در شبکه ایران‌اواس اجرا نمی‌شود.

**فناوری‌های کلیدی:** VRF، ZKP، Single Judicial API، Immutable Ledger

-----

### ۴. [پروتکل بازپس‌گیری](./reclaim-protocol-fa.md)

بازپس‌گیری دارایی‌های غصبی ظرف ۷۲ ساعت از استقرار سیستم. خزنده شبکه (Sovereign Crawler) یک هوش مصنوعی توزیع‌شده است که تمام لایه‌های پنهان و شرکت‌های پوششی (Shell Companies) را ردیابی و دارایی‌ها را منجمد می‌کند. مدیریت سه‌لایه‌ای صندوق ثروت ملی (نقد / مولد / گرو).

**فناوری‌های کلیدی:** Distributed AI، Smart Freeze، Multi-Sig، RWA Tokenization

**فرمول:** `V(L1) = Σ(C + G + A)` — حداقل ۳۰۰ میلیارد دلار در لایه نقد

-----

### ۵. [پروتکل دفاع](./defense-protocol-fa.md)

تفکیک کامل آرتش از سیاست و اقتصاد. زنجیره فرماندهی دیجیتال C4I با رمزنگاری آنی و غیرقابل جعل. پروتکل «دیدبان دیجیتال» (Digital Border) برای پوشش تمام مرزها با پهپاد و ماهواره. شفافیت کامل خرید تسلیحات از طریق API3 برای حذف دلالی و پورسانت.

**فناوری‌های کلیدی:** C4I Network، Sentinel Protocol، API3 Audit، RWA Transfer

-----

### ۶. [پروتکل حاکمیت](./governance-protocol-fa.md)

معماری مدیریت غیرمتمرکز استان‌ها با حفظ یکپارچگی ملی. فرمول ۳۰/۷۰ برای توزیع عادلانه درآمدهای استانی، انتخابات دیجیتال بیومتریک بدون شورای نگهبان، و پروتکل چک و تعادل (Check and Balance) میان مرکز و استان‌ها.

**فناوری‌های کلیدی:** Smart Contracts، Digital Voting، Oracle API3، Ombudsman Digital

