# Security Policy

Iran-OS is not production-ready.

The project currently does not claim:
- production readiness
- release approval
- completed external audit
- completed formal verification
- accepted evidence
- closed production-readiness blockers

## Reporting Security Issues

Please report security issues through GitHub Issues or Pull Requests only if they are framed as review findings, evidence gaps, or proposed remediations.

Do not report an issue as resolved, accepted, or production-blocker-closing unless the required evidence and reviewer signoff are attached or clearly linked.
