# تست‌های Iran-OS

این بخش شامل تست‌های فنی، امنیتی و حکمرانی پروژه Iran-OS است.

هدف این تست‌ها، بررسی عملکرد قراردادهای هوشمند، هسته حکمرانی، مکانیزم‌های امنیتی، صندوق ثروت ملی، لایه رفاه، هویت شهروندی و اجرای اصول منشور رفاه و عدالت است.

---

# ساختار تست‌ها

- `01_kernel.test.js` — بررسی عملکرد هسته حکمرانی

- `02_pahlavi_token.test.js` — بررسی پول دیجیتال پهلوی و محدودیت‌های نقدینگی

- `03_sovereign_wealth_fund.test.js` — تست صندوق ثروت ملی و ذخایر

- `04_constitution_guard.test.js` — جلوگیری از تخطی از منشور

- `05_citizen_card.test.js` — هویت و کارت شهروندی

- `06_asset_freeze.test.js` — فریز دارایی و مقابله با فساد

- `07_jury_selection.test.js` — انتخاب هیئت منصفه

- `08_treasury.test.js` — خزانه ملی

- `09_oracle_layer.test.js` — لایه اوراکل‌ها و داده‌های خارجی

- `10_welfare_distribution.test.js` — توزیع رفاه و خدمات عمومی

---

# هدف معماری تست‌ها

تمام تست‌ها باید تضمین کنند که:

- هیچ نهاد یا قرارداد هوشمندی نتواند برخلاف منشور عمل کند.

- سقف نقدینگی نقض نشود.

- شفافیت مالی حفظ شود.

- صندوق ثروت ملی قابل سوءاستفاده نباشد.

- حقوق شهروندی نقض نشود.

- لایه رفاه و خدمات عمومی پایدار باقی بماند.

# اصل بنیادین

Iran-OS تنها یک پروژه نرم‌افزاری نیست.

این تست‌ها برای تبدیل اصول منشور و سپیدنامه به سازوکارهای قابل اجرا، قابل ممیزی و قابل اعتماد طراحی شده‌اند.
