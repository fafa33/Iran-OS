# عامل‌های هوشمند IranOS

این پوشه معماری عامل‌های هوشمند (AI Agents) در سامانه IranOS را تعریف می‌کند.

عامل‌ها واحدهای اجرایی مستقل هستند که می‌توانند:

- تصمیم‌گیری محدود انجام دهند
- قوانین منشور را اجرا کنند
- گردش‌کارها را مدیریت کنند
- وضعیت کشور را تحلیل کنند
- هشدارهای امنیتی تولید کنند
- عملیات را ثبت و حسابرسی کنند

## ویژگی‌های اصلی عامل‌ها

- قابل حسابرسی
- دارای سطح دسترسی مشخص
- متصل به دفتر کل ملی
- متصل به قراردادهای هوشمند
- دارای محدودیت اختیارات
- قابل غیرفعال‌سازی اضطراری

## نمونه عامل‌ها

- عامل رفاه
- عامل سلامت
- عامل آموزش
- عامل مالیاتی
- عامل قضایی
- عامل نظارت مجلس
- عامل ماشه قانون اساسی
- عامل امنیت ملی

## معماری

هر عامل شامل این بخش‌هاست:

- ورودی‌ها
- حافظه
- موتور تصمیم
- سیاست‌های اجرایی
- ثبت عملیات
- لایه حسابرسی
- سطح اختیارات
