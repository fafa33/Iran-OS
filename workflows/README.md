# گردش‌کارهای IranOS

این پوشه برای تعریف گردش‌کارهای عملیاتی IranOS ساخته شده است.

هدف این بخش، تبدیل سپیدنامه و پروتکل‌های IranOS به فرایندهای اجرایی، قابل‌ردیابی، قابل‌حسابرسی و آماده برای پیاده‌سازی با عامل‌های هوشمند است.

## هر گردش‌کار باید مشخص کند

- رویداد آغازگر
- عامل‌های درگیر
- داده‌های ورودی
- مراحل اعتبارسنجی
- منطق تصمیم‌گیری
- ارتباط با قراردادها یا دفتر کل
- مسیر حسابرسی
- خروجی نهایی

## دسته‌بندی اولیه

- گردش‌کار پرداخت رفاه
- گردش‌کار هویت شهروندی
- گردش‌کار ماشه قانون اساسی
- گردش‌کار حمایت تولید
- گردش‌کار دادگستری دیجیتال
- گردش‌کار اوراکل‌های ملی
